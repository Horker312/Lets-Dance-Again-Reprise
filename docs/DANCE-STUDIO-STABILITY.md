# Dance Studio 안정성 수용 기준

적용 대상: Dance Studio 0.6.1 / LDA:R 0.7.7 기반 수정 브랜치 (2026-11-16). 이 문서는 **릴리스·실게임 검증 완료를 의미하지 않습니다.**

## 보존·복구 불변조건

- 프로젝트 열기에 실패해도 현재 편집 중인 프로젝트, 리그, 춤, 카메라, 음악, 저장 경로를 유지한다.
- 비유한 숫자, 잘못된 JSON, 크기 초과 파일을 거부하며 원본 프로젝트를 덮지 않는다.
- 프로젝트 저장 파일은 임시 파일을 준비한 뒤 교체한다. 임시 파일 삭제 실패가 본래 오류를 가리지 않게 기록한다.
- 게임 패키지는 스테이징 디렉터리에서 검증한 뒤 공개한다. 기존 출력은 명시적 승인 없이 수정/삭제하지 않는다.
- 이전 출력 아카이브는 재해시 검증과 백업 해시 검증을 통과해야만 정리할 수 있다.
- 게임 실행 중 패키지 교체를 거부하고, 경로 탈출/링크 경로/비정상 해시를 거부한다.
- XWMA 외부 디코더에는 시간과 출력 크기 제한을 적용하고, 종료 실패를 진단 로그에 남긴다.
- 복구 불가능한 UI 예외를 삼키고 계속 실행하지 않는다. 사용자에게 로그 경로를 표시한 후 종료한다.
- 긴 작업 중 UI 입력을 제한하며, 예외 후 바쁜 상태/버튼 잠금이 영구적으로 남지 않아야 한다.

## 자동 테스트

`python tools/check_hud_punctuation.py`: 기본 한/영 HUD 번역 문장과 C++ 내장 번역의 동기화 확인.

`DanceStudio.exe --stability-test <임시폴더>`: 프로젝트 저장·재로드, 불량 수치/JSON/크기 초과 거부, 카메라 전용 패키지 해시 검증 및 경로 탈출 거부. 테스트는 자체 임시 디렉터리에서만 파일을 생성·삭제한다.

기존 `--preservation-test`, `--content-test`, `--localization-test`, `--lifetime-test`, `--sync-mapping-test`도 반드시 회귀 검사 대상으로 유지한다.

## 별도의 Windows/MO2 실검증

.NET 10, 원본 HKX/WAV/XWMA, 외부 빌드 DLL/내장 스켈레톤이 준비된 환경에서 로드 중 예외·중단, 편집 상태 복원, XWMA 변환 오류, 기존 곡 패키지 백업/교체, 게임 실행 중 출력 차단, 인게임 재생을 확인한다. 저장소에는 편집기 필수 외부 DLL이 포함되지 않으므로 공개 소스만으로 컴파일·인게임 통과를 선언하지 않는다.
