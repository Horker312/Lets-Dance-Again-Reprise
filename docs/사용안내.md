# MFG + MFEE 및 HeadPart 사용 안내

LDA:R 0.5.15 / Dance Studio 0.5.8 / Facial Studio 0.5.1

## 설치
LDA:R ZIP은 MO2 전체 교체 설치용입니다. 곡 패키지·편집기·사용자 설정을 포함하지 않습니다.
기존 사용자 설정과 곡 패키지는 보관하세요. DLL 교체는 게임을 종료한 상태에서 진행하세요.
Dance Studio는 별도 MO2 ZIP의 `Tools/DanceStudio/DanceStudio.exe`, Facial Studio는 `FacialStudio.exe`입니다.
편집기는 .NET 10 Desktop Runtime이 필요합니다. EXE 옆 DLL/JSON을 함께 유지하세요.

## 표정
이제 게임용 출력과 런타임이 MFG + MFEE를 함께 지원합니다. 기존 MFG 항목을 MFEE 이름으로 변환하지 않습니다.
MFG: Expression 0~16, Modifier 0~13, Phoneme 0~15. MFG Fix 별도 API를 호출하거나 필수 인터페이스로 요구하지 않습니다.
MFEE가 없어도 MFG 경로는 API 교환 없이 실행됩니다. MFEE 모프만 MFEE API v7 및 해당 캐릭터 리소스가 필요합니다.
MFG Fix 설치 유무에 따른 게임 최종 합성 차이는 실게임 확인 전입니다. 입력 배열 값과 보이는 얼굴은 다를 수 있습니다.

Facial Studio의 **MFG 기본 표정**을 펼쳐 선택한 MFG 모프를 추가할 수 있습니다.
기존 MFEE 제작·강도·체크박스·클립 편집은 유지합니다. 모프 비활성화는 삭제/0과 다르며 강도를 보존합니다.
모음 단축 버튼은 기존 검증된 MFEE 매핑 정책을 유지합니다. MFG Aah 등은 MFG 목록에서 추가하세요.
이전 MFEE 전용 편집기에서 이미 제거해 내보낸 MFG는 DLL 업데이트만으로 되살아나지 않습니다. 원본 프로젝트에서 다시 내보내세요.

## HeadPart
1. 얼굴 NIF를 엽니다. 눈·눈꺼풀·눈썹·입 NIF가 별도 파일이면 **HeadPart NIF 추가**로 추가합니다.
2. **호환 TRI 찾기**는 같은 폴더의 파일명/메시명과 대응되는 기본 TRI 및 `_Extra.tri`만 제한적으로 찾습니다.
3. 정점 수·인덱스 토폴로지·기준 좌표가 일치하는 경우만 자동 연결합니다. 추가 TRI도 기존 기준 형상을 검증합니다.
4. 기준 좌표가 다르면 자동 연결하지 않습니다. 같은 정점 대응이 보존된 자료임을 확인한 후 **선택 부위 TRI 연결**에서 명시적으로 승인할 수 있습니다.
5. 선택 부위의 정점 수·TRI 모프 수와 누락 안내를 확인합니다. NIF만 추가해서는 표정이 변형되지 않습니다.
6. 사용한 설정은 `.facepreview.json`으로 따로 저장합니다. 곡 패키지에는 NIF/DDS/TRI가 들어가지 않습니다.

선택한 DDS·텍스처 폴더·재질은 유지합니다. 이번 업데이트는 색상·톤·피부·노멀맵·광택을 개선하거나 자동 변경하지 않습니다.
같은 NIF를 중복 추가하지 않습니다. 개별 부위의 오류는 경고하고 지원 가능한 나머지 부위는 유지합니다.
눈·속눈썹 TRI에 특정 모프의 델타가 없거나 0이면 그 부위는 움직이지 않습니다. 눈꺼풀을 덮도록 임의 변형하지 않습니다.
Dance Studio는 기존 머리 본 추적과 같은 공통 얼굴을 사용하며 촬영 FOV/경로/위치를 변경하지 않습니다.

## 긴 이름
프리셋/모프 이름은 말줄임표로 표시하고 마우스를 올리면 전체 이름을 보여줍니다. 모프 툴팁에는 백엔드·정확한 ID가 포함됩니다.
슬라이더·수치·삭제·체크박스를 유지하고 목록 가상화/스크롤을 유지합니다. Solo/개별 0 버튼은 추가하지 않았습니다.

## 혼합 예제
별도 예제 ZIP에는 프리셋과 표정 JSON만 있습니다. 곡/HKX/음악/얼굴 자산은 없습니다.
`mixed.facialpreset.json`을 Dance Studio에서 불러와 감정·눈·입에 배치하고 본인의 곡을 내보내세요.
예제: 0~3초 MoodHappy 25%, BrowUpLeft 25%, Aah 40% + MFEE MouthLaugh 20%, 3~4초 빈 구간.
직접 `facial.timeline.json`을 교체할 때는 `song.json` 참조·SHA256 갱신이 필요하므로 편집기 재출력을 권장합니다.
MFEE 미설치에서는 MouthLaugh만 제외되는지 확인하세요. Erin 예제 프로필은 리소스 제작 대상이며 임의 종족의 지원 증명이 아닙니다.
