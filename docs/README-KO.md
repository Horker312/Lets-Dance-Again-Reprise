# LDA:R / Dance Studio 소스 안내

- [본 모드 C++ 코드](../runtime/): 0.4.14 Photo Mode 일시정지 수정본 기준.
- [편집기 C# 코드](../editor/): Dance Studio 0.4.10 기준.
- [빌드 안내](BUILDING.md), [외부 자료/라이선스 경계](../THIRD_PARTY.md).
- 이 소스 공개 작업은 게임 기능을 새로 수정하거나 기존 곡을 포함하지 않습니다.

현재 본 모드 DLL은 Skyrim SE **1.5.97 전용**입니다. CommonLib 사용만으로 AE 1.6 계열이나 다른 버전이 지원되지는 않습니다. 실행 버전 제한·후킹 위치·구조체 및 빌드를 따로 검증해야 합니다.

루트 README의 버전은 소스 스냅샷을 뜻합니다. 동일한 0.4.14라도 초기 TokenFix와 이후 스케일/Photo Mode 수정본의 코드가 다릅니다. 현재 폴더는 최종 Photo Mode 수정본이며 초기 TokenFix 바이너리의 정확한 대응 소스라고 표기하지 않습니다.

본 모드의 음악 샘플 시계, 독립 FPS, 카메라 추적, 준비/재생/정지, Space 일시정지, 곡·카메라 독립 선택 코드를 포함합니다. 편집기 타임라인·오디오 입력·HKX 보존·패키지 출력 소스와 테스트 코드도 포함합니다.

외부 스켈레톤과 DLL은 Git에 올리지 않습니다. 별도 빌드 입력으로 가져와 컴파일할 수 있지만, 특히 Matcher/HKX2E의 실제 의존성 소스는 추가 확보가 필요합니다. 저장소 공개만으로 모든 배포 라이선스 의무가 완료됐다고 주장하지 않습니다.
