# 최신 RC 변경·검증

LDA:R 0.7.1 / Dance Studio 0.6.1 / Facial Studio 0.6.0 기준입니다. 세 프로그램의 최신 개발 소스를 반영했으며 외부 실행 바이너리는 새로 공개하지 않았습니다.

## LDA:R

- 최대 5인·NPC-only 공연과 개별 카메라 기준을 지원합니다. 플레이어 marker는 같은 셀의 실제 공연 시작에 사용하며 플레이어를 배치 위치에 고정하지 않습니다.
- NPC는 등록만으로 행동을 끊지 않습니다. 배치 확정 시 액터 단위 Scene 연결 분리·전투 중단·restrained 제어를 사용합니다. 퀘스트 단계/전역 변수를 수정하거나 Scene 전체를 중단하지 않습니다.
- 같은 셀에서 일반 AI로 이동한 NPC는 약 0.2초 간격으로 복귀시킵니다. 연속 5회 실패하면 기존 안전 해제·유한 복구 큐로 넘깁니다. 공연 중에는 위치를 고정하지 않습니다.
- 이전 복구 기록을 먼저 안전하게 정리한 뒤 새 배치 제어를 확보합니다. 실패/보류 기록을 지우거나 이전 큐가 새 제어를 해제하도록 두지 않습니다.
- 사망/삭제/비활성화/셀 이동/위험 상태는 보호합니다. 나짐의 원본 고유 참조만 등록을 제한하고 복제 참조와 다른 NPC는 제외하지 않습니다.
- 기존 카메라 반환 확인 후 정리, WinMM 오류 소유권, 개별 표정 복구, 음악 샘플 시계는 유지합니다.

## 두 편집기

- Dance Studio는 새 패키지에 성별 하위 모션만 출력합니다. 기존 대표 경로는 하위 경로로 해석하며 최상위 모션의 검증을 제거했습니다. 하위 파일·음악·카메라·표정 해시는 유지합니다.
- 곡 업데이트의 ID 보존, 독립 신규 ID, 원본 변경 감지·재연결·실패 복구와 타임라인 조작 개선을 포함합니다.
- Facial Studio 0.6.0은 자동 HeadPart/NIF/TRI/DDS 연결, 요청 취소·최신 결과만 적용, Data 경로 저장·환경 확인, 실패 시 기존 작업 유지, 자동 안정 ID와 드래그 조작 개선을 포함합니다.
- .jslot에 없는 종족 기본 형상이나 게임 셰이더·눈/턱 합성을 완전히 재현하지 않습니다. 미리보기를 게임 최종 얼굴과 같다고 보장하지 않습니다.

## 수행한 검사

- 최신 강제 배치 DLL: MSVC x64 Release compile/resource/link, 소스/바이너리 지문 일치, 변경 생산 코드 기반 모의 검사 **40개 PASS**.
- 성별 모션 전용 변경: 편집기 Release, 출력/회귀 **91개 PASS**, 신규 4종·실제 과거 패키지 6개 로딩과 잘못된 여성/남성 해시 거부 PASS.
- 편집기 게시 EXE의 WPF 렌더링·실제 오디오 장치 시계 진행·프레임 스텝·종료 PASS.
- Facial Studio 0.6.0에서 기존 핵심 54개·별도 WPF 10개 및 별도 프로세스의 경로 복원 검사 결과를 유지합니다. 이번 저장소 업로드 중 다시 실행한 검사는 아닙니다.
- 정리본에서 실행 파일·DLL·ESL·필수 JSON·라이선스 유지 및 ZIP 무결성을 확인했습니다. 개발용 보고서·스모크 결과·테스트 스켈레톤 예제만 설치본에서 정리했습니다.

## 미검증과 제한

**실제 Skyrim 경비병·퀘스트 Scene·ESC·Alt+Tab·AI/위치 복구, 실제 MO2 프로필 전환과 실제 마우스 드래그는 미검증입니다.** 액터 Scene 연결 분리 뒤 원래 Scene의 완전한 재개는 보장하지 않습니다. 복구는 개별 상태 비교와 제한된 재시도 정책을 유지합니다.

사용자가 직전 시험에서 최상위 모션 파일 없이 춤 재생을 확인했습니다. 이를 최신 전체 RC의 모든 게임 조합 검증으로 확대하지 않습니다. CRDW 캐시 미생성 환경의 A포즈 관측과 팝업 비활성화/Accelerate 같은 미검증 제안을 구분합니다.

현재 외부 HKX2E/Matcher DLL과 내장 XPMSSE 스켈레톤의 정확한 소스/재배포 근거가 모두 확보된 것은 아닙니다. 기능은 유지하되 해당 파일을 이 소스 업로드에 넣지 않았습니다. 실제 XWM 압축 샘플 디코딩, 고DPI/장시간 세션과 AE 게임 동작도 추가 확인 대상입니다.
