# LDA:R 0.4.14 — 일시정지 / Photo Mode 호환 수정

선택 토큰 충돌 수정과 XYZ 카메라 경로 스케일 보정을 포함한 곡 미포함 풀버전입니다. 편집기와 곡 패키지는 변경하지 않습니다. 버전 번호는 0.4.14 그대로입니다.

## 동작
Space는 Reprise 사용자 정지 상태만 바꿉니다. Photo Mode 시간 정지, 게임/메뉴 정지, 포커스 이탈, 그래프 준비 미완료 등은 별도의 정지 이유로 합칩니다. 한 이유를 해제해도 다른 이유가 남으면 재개하지 않습니다. Reprise는 게임의 freezeTime을 직접 변경하지 않습니다.
사용자 정지 상태는 Photo Mode를 열고 닫는 동안 유지하며 세션 완전 종료/월드 초기화 때 정리합니다. 시간 정지 중 재생을 시작해도 음악을 먼저 잠깐 켜지 않도록 시작부의 무조건 재개를 제거했습니다. 재개는 게임 스레드의 통합 판단 한곳에서만 허용하며 장치 잠금 안에서 이유를 다시 확인합니다.

## 정지 지연 대응
Photo Mode 공개 Time.cpp의 정지 체크박스는 게임의 freezeTime을 직접 변경합니다. Reprise는 기존 메인 업데이트 전후 감지에 더해 선택된 춤의 애니메이션 처리에서도 현재 freezeTime을 확인합니다. 이전 Playback 스냅샷이 재생 가능으로 남아 있어도 새 정지 신호가 있으면 진단용 일반 재생을 진행하지 않고 오디오도 정지시킵니다. Space도 입력 디스패치 단계에서 사용자 정지 요청을 반영합니다. 별도 고속 폴링 스레드나 Photo Mode 내부 주소 후킹은 추가하지 않습니다.
공개 소스: https://github.com/powerof3/PhotoMode/blob/master/src/PhotoMode/Tabs/Time.cpp
이는 관측 가능한 정지 신호를 더 이른 경로에서 처리하는 보완입니다. Photo Mode 자체에서 신호를 쓰기 전의 UI 처리 시간, 이미 표시된 렌더 프레임, 오디오 장치 버퍼 지연까지 절대 0ms로 만들었다는 뜻은 아닙니다. 설치된 Photo Mode와의 실제 클릭 체감은 게임에서 확인해야 합니다.

## 카메라와 복구
Photo Mode가 활성 상태면 회전/이동 훅도 원래 카메라 경로를 사용하며 Reprise가 카메라/FOV를 되찾지 않습니다. Photo Mode 종료 후 전용 카메라는 현재 곡 시점으로 복귀하되 사용자 일시정지가 남으면 음악과 춤은 계속 정지합니다. 준비 중 카메라 보정도 Photo Mode 활성 상태에서는 수행하지 않습니다. 종료 중 FOV 복구는 기존 소유권 확인/지연 복구를 유지합니다.
음악 샘플 시계, 춤/카메라 독립 FPS, 곡 파일, 원본 HKX 보존 및 XYZ 스케일 경로는 유지합니다.

## 검증
DLL compile/link 성공. 정지 정책·소유권·빠른 freeze 감지/재개 검사 63개, 기존 카메라/스케일/선택/세션 검사 150개, 실제 WinMM 장치의 정지 유지 및 재개 검사 8개 통과. 총 221개입니다.
실제 Skyrim과 Photo Mode UI 조합은 미검증입니다. Space 정지 → Photo Mode 정지·해제·종료 뒤에도 정지 유지, Photo Mode만으로 정지/재개, 정지 상태에서 재생 시작, Photo Mode 안에서 춤 종료, 작은/큰 키 카메라 구도를 확인해주세요. 게임을 완전히 재시작한 뒤 적용합니다. 편집기 업데이트·곡 재내보내기는 필요하지 않습니다.

변경 파일: runtime/PausePolicy.h(추가), AudioDevice.h, plugin.cpp. 로그의 Playback pause reasons는 비트 합계이며 User=1, Freeze=2, Game=4, Menu=8, Settings=16, Focus=32, Graph=64, NoSession=128입니다.
