# Dance Studio 네이티브 런타임 0.2

`plugin.cpp`는 Skyrim SE 1.5.97용 SKSE 어댑터입니다. `SessionCore.h`의 준비·시작·중단 정책을 OAR·내장 FreeCameraState·카메라 배우·WinMM 오디오와 연결합니다. Papyrus는 사용하지 않습니다.

파일 검사와 PCM/카메라 읽기는 엔진 객체를 건드리지 않는 비동기 작업에서 수행합니다. 게임 객체 생성·복구는 게임 업데이트 스레드에서 수행합니다. 애니메이션 후킹은 플레이어의 선택된 OAR 클립에 한정하며 NPC 경로는 원래 함수로 전달합니다. 원래 함수 포인터를 먼저 초기화한 뒤 후크를 공개합니다.

모션 바인딩·Generate 관측과 카메라 3D가 준비된 뒤에만 Armed 상태로 들어갑니다. 입력 당시 Preparing이었으면 시작 요청을 버립니다. 오디오 시계는 무음 실장치 시험으로 진행·일시정지·재개를 확인했습니다. 드라이버가 버퍼 해제를 거부하면 버퍼를 재사용하지 않습니다.

공개 API의 Generate 함수는 5개 인자입니다. CommonLib의 불완전한 2개 인자 선언을 그대로 후킹하지 않았습니다. SE-only SDK·ActorState 오프셋·주요 Havok 구조 크기를 빌드에서 검사합니다. MO2의 가상 Data 경로를 물리 경로로 바꾸지 않습니다.

사용법과 게임 확인 항목은 상위 폴더의 RUNTIME-README-KO.md에 있습니다. 빌드와 오프라인 검사를 통과했지만 실제 Skyrim 내 성공을 확인한 상태는 아닙니다.
