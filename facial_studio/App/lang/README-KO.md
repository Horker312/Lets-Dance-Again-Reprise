# Facial Studio 번역 팩

`Tools/FacialStudio/lang/`에 UTF-8 JSON 파일을 넣고 Facial Studio를 다시 실행합니다. 왼쪽 언어 목록에서 추가된 언어 이름을 선택해야 적용됩니다. 파일 발견만으로 현재 언어가 바뀌지 않습니다.

파일 형식:
```json
{"schemaVersion":1,"id":"fr","name":"Français","strings":{"저장":"Enregistrer","불러오기":"Ouvrir"}}
```

`id`는 소문자로 시작하는 ASCII 소문자/숫자/밑줄/하이픈 2~32자입니다. `ko`, `en`은 내장 언어로 예약되어 있습니다. `name`은 목록에 보일 이름입니다. `strings`의 왼쪽 한국어 키는 바꾸지 않고 오른쪽 값만 번역합니다. `{0}`, `{1}` 같은 자리표시자는 개수와 번호를 유지하세요. 모프 ID, 파일명, 종족/자산 경로 등 내부 데이터는 번역하지 않습니다.

`translation-template.json.example`은 모든 영어 기본 문구를 담은 번역 작업용 원본입니다. 복사하여 `.json` 확장자로 저장하고 `id`/`name`/오른쪽 문구를 번역하세요. 예제는 완성된 외국어 번역으로 제공되는 것이 아닙니다.

빠진 문구는 영어, 영어 키가 없는 문구는 한국어로 표시합니다. 손상된 파일과 잘못된 항목은 무시합니다. 서로 같은 외부 ID가 있으면 충돌하는 팩을 모두 목록에서 제외합니다. 한 폴더는 최대64개의 `.json`을 허용하며 초과하면 외부 팩 전체를 로드하지 않습니다. 파일 하나는 최대1MiB입니다. 현재 선택한 팩이 삭제되면 다음 시작 시 한국어로 복귀합니다.

선택값은 사용자 LocalAppData/FacialStudio/language.json에 저장됩니다. 얼굴·TRI·프리셋·클립 원본에는 번역을 기록하지 않습니다. 텍스트 입력값과 목록의 사용자 프리셋 이름도 번역하지 않습니다.

Dance Studio 및 LDA:R 팩과 바깥 형식은 같지만 문구 키는 제품마다 다릅니다. 다른 제품용 JSON을 그대로 넣지 말고 그 제품의 템플릿을 사용하세요. 사용자 언어의 글꼴이 Windows에 설치되어 있어야 할 수 있습니다.
